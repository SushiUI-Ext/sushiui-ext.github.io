About

SushiUI Extended is a restructured version of SushiUI. It uses its own build system based on GNU Make with a minimal toolchain: just gmake and bash. This archive hosts the device tree for the bangkk, the Moto G84 5G.

SushiUI Extended is an independent project. Device trees are published as source on GitHub.
